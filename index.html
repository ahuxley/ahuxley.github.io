Featured Project

American Battery Solutions

Infrastructure Monitoring ETL Pipeline & Power BI Dashboard

Architected an automated end-to-end ETL pipeline (hawkeye_etl) that pulls infrastructure and ticketing data from Zabbix and Service Desk Plus REST APIs into a SQL Server backend, flattening complex nested JSON into relational reporting tables.

On top of it sits an 8-page Power BI report — Monitoring Health, Hosts, Zabbix, Service Desk, Service Risk & Trends, Capacity, Bandwidth, and a technician Leaderboard — built on a composite DirectQuery model of 20 tables and 26 relationships.

  • Automated Telemetry Ingestion: Built hawkeye_etl pulling Zabbix & Service Desk Plus APIs into SQL Server, eliminating manual IT auditing across 100+ host environments
  • 106 DAX Measures: Modeled operational KPIs including SLA Compliance %, Mean Time To Resolve, Host Availability %, and Monitoring Coverage Score, organized into display folders by audience
  • Pipeline Observability: Surfaced the pipeline's own health in-report via ETL Run Log and contract-status tables, alongside data-freshness indicators on each source
  • Accessible Alerting: Paired every conditional-format color with a text or glyph label, so severity is never communicated by color alone
  • Production Infrastructure: Sized and deployed Hyper-V VM hosting Windows Server & SQL Server 2025 for production pipeline execution

Personal Project

CardMap

CardMap is a full-stack web app for finding local Magic: The Gathering card inventory by ZIP code or GPS location, built on React, TypeScript, and a Postgres/PostGIS backend.

The hard part is that neither input is clean: players mistype card names, and geolocation providers go down.

  • Built full-text search with trigram-similarity fallback so imperfect card names still return the right results
  • Implemented a serverless reverse-geocoding endpoint with multi-provider fallback (BigDataCloud, Nominatim) for GPS-based search
  • Enforced Postgres Row-Level Security policies and RPC functions, including a decklist import feature
